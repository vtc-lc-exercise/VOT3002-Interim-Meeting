⏱️ IA02 Time Limits

  • 5-student group 15-20 mins
  • 4-student group 12-16 mins
  • 3-student group 9-12 mins
⚠️

Important Reminders

  • ✂️
    Skip TA02 Content No need to present Background, Purpose, or Methodology again.
  • 🎯
    Select Key Info Guide students to select only the most crucial points.
  • 🚫
    Language Consistency Avoid code-mixing. A group MUST use a consistent language.
    Otherwise, MAX 3 marks for Language.
